## How dialogue is tied to knowledge

Every NPC line that matters is a **check against the intel journal**, not a
menu pick:

```json
{ "text": "'Greldok.'",
  "check": { "has": "know_troll_name", "min_reliability": 0.5 },
  "next_pass": "name_right", "next_fail": "name_bluff" }
```

* The answer is *always offered as text* â€” you can try to bluff.
* It only **works** if the journal holds the token at sufficient reliability.
  The troll's own taunt teaches `know_troll_name` at 0.2 (not enough); the
  carving under the cellar stairs teaches it at 0.85 (enough).
* Wrong answers come from **false rumours** (`rumor_troll_name_false`, from the
  attic crayon scrawl). Picking one routes to `next_fail`, and the true/false
  pair is linked via `conflicts` so exposing the lie corroborates the truth.
* Nodes can `debunk` a token (reliability -> 0, marked FALSE in the journal),
  `grant_intel` with a reliability, `set_flags`, `give_items`/`take_items`,
  award `score`, turn the speaker `hostile`, or `despawn` him.
* Choices can require items (`requires_item`) or knowledge (`requires`); the
  thief's "Address him by name" only appears once you know two things about him.

Non-knowledge routes exist too: garlic breath routs the troll; lunch + water
puts the cyclops to sleep; a wounded thief (below 35% health) stops fighting
and offers terms.

**The thief is alive**: he wanders the Gallery and lifts one treasure from
your pack whenever he brushes past (30 s cooldown) â€” until you name him.

## Adding a room

1. Add an entry to `maps.json` (description, `short_description`, spawns,
   portals). Set `"dark": true` for anything underground.
2. Add a line to `ROOMS` in `tools/gen_scenes.py` and run it (or hand-build a
   `.tscn` whose root has `map_root.gd`; `Marker3D`s named `POI_<id>`,
   `Portal_<id>`, `Spawn_<key>` override JSON positions).
3. Drop objects into `pois.json` (`examine`, `pickup`, `container`, `dialogue`).
4. `python game_api/fps/tools/validate_data.py games/zork` then
   `./tools/sync_game.ps1 -Game zork`.
